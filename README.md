

# BLDC 控制子系统（Steering-by-wire Chassis）

## 简介

本项目是一个基于 STM32F407 平台的双电机无刷直流电机（BLDC）控制固件，用于线控转向底盘的差速驱动控制。通过解析遥控器 PWM 信号，控制双电机协同工作，实现车辆前进、后退和转向功能。

## 主要功能

- **双电机独立控制**：支持两台 BLDC 电机独立控制
- **差速转向算法**：基于 X 轴速度和 Z 轴角速度的差速驱动算法
- **遥控器信号解析**：解析 PWM 信号控制底盘运动
- **霍尔传感器反馈**：实时监测电机位置和方向
- **CAN 通信**：支持 CAN 总线通信，用于系统状态监控
- **PWM 六步换相**：实现 BLDC 电机的精确控制
- **电机保护机制**：过流、堵转保护

### 核心模块

- **bldc.c/bldc.h**：BLDC 电机驱动核心，实现六步换相算法
- **chassis.c/chassis.h**：底盘运动控制，实现差速驱动运动学模型
- **pwm_duty_analyzer.c**：遥控器 PWM 信号解析
- **can.c**：CAN 总线通信
- **usart.c**：串口调试输出

## 构建与烧写

### 环境要求

- ARM GCC 编译器
- CMake 3.15+
- ST-Link 调试器（或 OpenOCD）

### 编译步骤

```bash
# 创建构建目录
mkdir build
cd build

# 配置项目
cmake .. -DCMAKE_TOOLCHAIN_FILE=../cmake/gcc-arm-none-eabi.cmake

# 编译
make
```

### 烧写固件

使用 ST-Link 烧录：

```bash
st-flash write firmware.bin 0x8000000
```

或使用 OpenOCD + GDB 进行调试。

## 运行与控制

### 遥控器控制

- **通道 2**：控制 X 轴速度（前进/后退）
- **通道 4**：控制 Z 轴角速度（左转/右转）

### 状态指示

- **LED0**：系统运行状态指示（200ms 闪烁）
- **CAN 总线**：发送心跳包（ID: 0x01）
- **串口输出**：调试信息（速度、PWM 值等）

### 控制算法

底盘运动学模型：

```
左电机目标速度 = velocity_x + velocity_z
右电机目标速度 = velocity_x - velocity_z
```

其中：
- `velocity_x`: X 轴方向速度分量（前进/后退）
- `velocity_z`: Z 轴方向角速度分量（左转/右转）

## 调试与故障排查

### 常见问题及解决方案

1. **电机无法启动**
   - 检查电源电压是否正常
   - 确认 PWM 输出配置
   - 验证半桥驱动芯片使能信号

2. **电机反转**
   - 检查霍尔传感器相序
   - 验证换相表是否正确

3. **遥控器信号不响应**
   - 确认 ADC 采样配置
   - 检查遥控器零点校准

4. **CAN 通信失败**
   - 检查 CAN 终端电阻（通常为 120Ω）
   - 确认波特率设置

5. **电机抖动或异响**
   - 检查 PWM 频率设置
   - 验证死区时间配置

## 安全注意事项

- 调试阶段使用限流电源，限制输出电流以防损坏电机或驱动器
- 首次上电前仔细检查接线，避免电源极性接反
- 运行时注意电机和驱动器温升，避免过热
- 紧急情况下立即断电
