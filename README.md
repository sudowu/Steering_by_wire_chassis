# BLDC 控制子系统（Steering-by-wire Chassis）

简介
---
本目录包含用于线控转向底盘的双电机无刷直流电机（BLDC）控制固件。基于STM32F407平台实现差速驱动控制，通过遥控器信号控制双电机协同工作，实现车辆前进、后退和转向功能。

主要功能
---
- 双电机独立控制：支持两台BLDC电机独立控制
- 差速转向算法：基于X轴速度和Z轴角速度的差速驱动算法
- 遥控器信号解析：解析PWM信号控制底盘运动
- 霍尔传感器反馈：实时监测电机位置和方向
- CAN通信：支持CAN总线通信
- PWM六步换相：实现BLDC电机的精确控制
- 电机保护机制：过流、堵转保护

硬件配置
---
- MCU: STM32F407VET6
- 电机驱动器: 半桥驱动芯片（如DRV8305等）
- 位置传感器: 霍尔传感器（三路方波信号）
- 电源管理: 12V驱动电源与3.3V/5V控制电源分离
- 通信接口: CAN总线、UART调试接口
- 输入设备: 遥控接收机（PWM信号输入）
- 输出设备: 双电机驱动输出

软件架构
---
- 底层驱动：STM32 HAL库
- 电机控制：六步换相算法
- 底盘控制：差速驱动运动学模型
- 通信协议：CAN通信协议

引脚分配
---
**电机1控制（左电机）**
- PWM U相：TIM1_CH1 (PA8)
- PWM V相：TIM1_CH2 (PA9)
- PWM W相：TIM1_CH3 (PA10)
- 低侧开关U：PA0
- 低侧开关V：PA1
- 低侧开关W：PA2
- 霍尔传感器U：PA6 (TIM3_CH1)
- 霍尔传感器V：PA7 (TIM3_CH2)
- 霍尔传感器W：PB0 (TIM3_CH3)
- 关断控制：PC0

**电机2控制（右电机）**
- PWM U相：TIM8_CH1 (PC6)
- PWM V相：TIM8_CH2 (PC7)
- PWM W相：TIM8_CH3 (PC8)
- 低侧开关U：PC1
- 低侧开关V：PC2
- 低侧开关W：PC3
- 霍尔传感器U：PC9 (TIM8_CH4)
- 霍尔传感器V：PB4 (TIM3_CH1)
- 霍尔传感器W：PB5 (TIM3_CH2)
- 关断控制：PC13

**其他接口**
- CAN通信：PB8 (CAN_RX), PB9 (CAN_TX)
- 遥控器PWM输入：PC4 (ADC1), PC5 (ADC2)
- LED指示灯：PB10, PB11
- 按键输入：PC10, PC11, PC12

构建与烧写
---
1. 使用STM32CubeMX打开[BLDC.ioc](file:///E:/STM32/Steering_by_wire_chassis/BLDC/BLDC.ioc)文件，检查外设配置
2. 生成HAL库代码并导入到IDE中
3. 使用ARM-GCC编译项目：
   ```
   mkdir build
   cd build
   cmake .. -DCMAKE_TOOLCHAIN_FILE=../cmake/gcc-arm-none-eabi.cmake
   make
   ```
4. 使用ST-Link烧录固件：
   - 通过STM32CubeProgrammer GUI
   - 或使用命令行：`st-flash write firmware.bin 0x8000000`
   - 或使用OpenOCD + GDB进行调试

运行与控制
---
- 遥控器通道2：控制X轴速度（前进/后退）
- 遥控器通道4：控制Z轴角速度（左转/右转）
- LED0：系统运行状态指示（200ms闪烁）
- CAN总线：发送心跳包（ID:0x01）
- 串口输出：调试信息（速度、PWM值等）

控制算法说明
---
底盘运动学模型：
- 左电机目标速度 = velocity_x + velocity_z
- 右电机目标速度 = velocity_x - velocity_z

其中：
- velocity_x: X轴方向速度分量（前进/后退）
- velocity_z: Z轴方向角速度分量（左转/右转）

调试与故障排查
---
**常见问题及解决方案：**

1. 电机无法启动
   - 检查电源电压是否正常
   - 确认PWM输出配置
   - 验证半桥驱动芯片使能信号

2. 电机反转
   - 检查霍尔传感器相序
   - 验证换相表是否正确

3. 遥控器信号不响应
   - 确认ADC采样配置
   - 检查遥控器零点校准

4. CAN通信失败
   - 检查CAN终端电阻（通常为120Ω）
   - 确认波特率设置

5. 电机抖动或异响
   - 检查PWM频率设置
   - 验证死区时间配置

安全注意事项
---
- 调试阶段使用限流电源，限制输出电流以防损坏电机或驱动器
- 首次上电前仔细检查接线，避免电源极性接反
- 运行时注意电机和驱动器温升，避免过热
- 紧急情况下立即断电

技术规格
---
- 工作电压：12V DC（电机），5V/3.3V（控制）
- PWM频率：约24kHz
- 控制频率：100Hz（主循环）
- 通信速率：CAN总线，波特率待配置
- 电机类型：三相无刷直流电机（需霍尔传感器）
